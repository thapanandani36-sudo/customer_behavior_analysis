# Data Analytics Project

## Overview

This project demonstrates an end-to-end Data Analytics workflow, starting from data collection and preprocessing to visualization and reporting. The objective is to extract meaningful insights from the dataset using Python, SQL, and Power BI.

## Dataset

The dataset contains structured data used for analysis and visualization. It was imported into Python for exploratory analysis, cleaned for quality improvement, stored in a relational database, and visualized through an interactive dashboard.

## Tools & Technologies

* **Python**

  * Pandas
  * NumPy
  * Matplotlib
  * Seaborn
* **SQL**

  * PostgreSQL / MySQL / SQL Server
* **Power BI**
* **Jupyter Notebook**
* **Gamma AI** (Presentation Creation)

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python using Pandas.
* Examined data structure, columns, and data types.

### 2. Exploratory Data Analysis (EDA)

* Generated summary statistics.
* Analyzed distributions and trends.
* Identified missing values and outliers.
* Created visualizations for better understanding.

### 3. Data Cleaning

* Removed duplicate records.
* Handled missing values.
* Corrected inconsistent data formats.
* Prepared data for analysis and reporting.

### 4. SQL Analysis

* Imported cleaned data into PostgreSQL/MySQL/SQL Server.
* Created tables and relationships.
* Executed SQL queries to:

  * Filter records
  * Aggregate data
  * Generate KPIs
  * Extract business insights

### 5. Power BI Dashboard

Built an interactive dashboard featuring:

* Key Performance Indicators (KPIs)
* Trend Analysis
* Category-wise Performance
* Interactive Filters and Slicers
* Business Insights Visualization

### 6. Reporting

* Summarized findings and recommendations.
* Documented analysis process and outcomes.
* Highlighted key trends and actionable insights.

### 7. Presentation (Gamma)

* Created a professional presentation using Gamma AI.
* Included project overview, methodology, dashboard screenshots, insights, and conclusions.

## Dashboard Features

## Key Results

## How to Run

### Python Analysis

1. Install required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn
   ```
2. Open Jupyter Notebook.
3. Run the notebooks in sequence:

   * Data Loading
   * EDA
   * Data Cleaning

### SQL Analysis

1. Create a database in PostgreSQL/MySQL/SQL Server.
2. Import the cleaned dataset.
3. Execute the SQL queries provided in the SQL folder.

### Power BI Dashboard

1. Open the `.pbix` file in Power BI Desktop.
2. Refresh the dataset connection.
3. Explore the interactive dashboard.
